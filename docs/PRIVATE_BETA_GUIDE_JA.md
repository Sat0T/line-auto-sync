# LINE Auto Sync RC3 — 技術レビュー参加者向け案内（配布未承認）

2026年10月28日時点の開発候補です。LINE公式製品ではありません。
**まだ他人の端末への導入を推奨せず、.debの公開配布も許可していません。**
まず公開ソースと合成データだけで技術レビューを受ける段階です。

## 対象とできないこと

対象：rootless脱獄iOSでの「通常LINE」のメッセージ読み取り、
端末内の未送信キュー保存、手動HTTPS転送。初期状態は同期無効です。

対象外：OpenChat、添付ファイル・編集の完全同期、長文の自動回復、
バックグラウンド自動起動、GUI、個人用のGAS・カレンダー・タスク処理。

RC3の送信方式はトークン付きJSONと文字列OKの組合せです。
HMAC v2通信とは別物であり、受信側の仕様不一致では動きません。

## 現在までの根拠

- 合成SQLiteと差し替えHTTPを使うオフラインテスト
- Windows/Linux × Python3.9/3.12のCI実行
- rootless .deb候補のビルドと内容照合
- 追加レビューでは、設定・キャッシュのsymlink防御、HTTPS
  リダイレクト制限、受信側の模擬重複排除テストを拡充

**実LINE DB、独立したiOS端末、実GASへの送信は未検証です。**
オフラインテスト成功は実機互換性や個人情報保護の保証ではありません。

## もし技術レビューに協力いただける場合

- GitHub上のコードと問題のある実装経路を指摘してください。
- 再現データは架空のメッセージ・架空のユーザー・ローカルDBのみ。
- 実際のLINE DB、認証トークン、GAS URL、メールアドレス、
  会話内容、端末ID、個人のファイルパスをGitHubに投稿しないでください。
- 送信前ACK、受信直後のクラッシュ、同じバッチの再送、部分受理、
  ソースID・メッセージIDの衝突、アンインストール後のデータ残存を
  特に確認してください。
- 実機テストが許可された場合も、稼働中の個人用iPadではなく
  許可された独立端末を使い、最初は合成DBで試します。
